# Отчёт по автоматизации тестирования

## Что было запланировано

Планировалась автоматизация следующих сценариев:

* успешная оплата валидной картой;
* отклонённая оплата невалидной картой;
* проверка валидации поля «Месяц»;
* проверка валидации поля «Год»;
* проверка поля «Владелец»;
* проверка поля CVC.

Для автоматизации использовались следующие инструменты:

* Selenium WebDriver
* Pytest
* Allure
* Docker
* MySQL

---

## Что было реализовано

Было реализовано **6 UI-автотестов**, проверяющих основные сценарии оплаты.

Автотесты выполняют:

* заполнение формы оплаты;
* проверку уведомлений интерфейса;
* проверку записей в базе данных.

При запуске автотестов:

* **4 теста проходят успешно**
* **2 теста падают**

Падение тестов связано с ранее обнаруженными дефектами приложения.

---

## Сработавшие риски

В процессе автоматизации возникли следующие сложности:

* необходимость самостоятельно определять локаторы элементов интерфейса;
* настройка Docker-окружения;
* подключение тестов к базе данных;
* интеграция Allure-отчётов.

---

## Итог по времени

Планируемое время: **17–23 часа**

Фактически затраченное время: **около 30 часов**, что связано с изучением инструментов автоматизации и настройкой тестового окружения.

---

## Итог

Основные пользовательские сценарии оплаты успешно покрыты автоматизированными тестами.
Тесты интегрированы с системой отчётности Allure и могут запускаться автоматически через Pytest.
