# Отчёт о тестировании

## Краткое описание

Проведено тестирование веб-сервиса покупки тура с оплатой банковской картой или оформлением кредита.
Тестирование включало проверку корректности обработки платежей, валидации полей формы и отображения уведомлений пользователю.

Тестирование проводилось с использованием ручных тестов и автоматизированных UI-тестов.

---

## Количество тест-кейсов

Всего подготовлено тест-кейсов: **6**

| Результат        | Количество |
| ---------------- | ---------- |
| Успешно пройдено | 4          |
| Не пройдено      | 2          |

Процент успешных тестов: **66%**
Процент неуспешных тестов: **34%**

---

## Найденные дефекты

В ходе тестирования было обнаружено **4 дефекта**.

Некоторые из обнаруженных дефектов приводят к падению автотестов. Например:

* поле **«Владелец»** принимает невалидные значения;
* при вводе невалидного номера карты отображается сообщение об успешной операции, хотя в базе данных операция отклоняется.

Эти дефекты воспроизводятся автоматически при запуске тестов.

---

## Общие рекомендации

1. Улучшить валидацию полей формы оплаты.
2. Проверять соответствие сообщений пользователю фактическому результату операции.
3. Добавить дополнительные проверки на стороне сервера.
4. Расширить покрытие автотестами для граничных значений полей формы.
