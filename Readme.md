# Автоматизация тестирования сервиса покупки тура

Проект содержит автоматизированные UI-тесты для проверки сервиса покупки тура с оплатой банковской картой или оформлением кредита.

Тесты написаны с использованием:

* Python
* Selenium WebDriver
* Pytest
* Allure
* Docker
* MySQL

---

# Предварительные требования

Перед запуском необходимо установить:

1. **Python 3.10+**
2. **Docker Desktop**
3. **Google Chrome**
4. **Allure**

## Установка зависимостей Python

Создать и активировать виртуальное окружение:

Windows:

```
python -m venv .venv
.venv\Scripts\activate
```

Установить зависимости:

```
pip install -r requirements.txt
```

---

# Запуск тестового приложения

Запустить контейнеры Docker:

```
docker compose up

или

docker-compose up
```

После запуска приложение будет доступно по адресу:

```
http://localhost:8080
```

База данных MySQL будет доступна на порту:

```
localhost:3307
```

---

# Запуск автотестов

Запустить тесты с генерацией отчёта Allure:

```
pytest --alluredir=allure-results
```

После выполнения тестов появится папка:

```
allure-results
```

---

# Просмотр отчёта Allure

Сгенерировать и открыть отчёт:

```
allure serve allure-results
```

После выполнения команды автоматически откроется браузер с отчётом о тестировании.
