# План автоматизации тестирования

## 1. Перечень автоматизируемых сценариев

Планируется автоматизация следующих пользовательских сценариев для сценария оформления тура с оплатой по карте:

1. Успешная оплата по карте с валидными данными.
2. Отклонённая оплата по карте с невалидной картой.
3. Проверка валидации поля "Месяц" при вводе некорректного значения (00).
4. Проверка валидации поля "Год" при вводе некорректного значения (25)
5. Проверка валидации поля "Владелец" при вводе имени, содержащего цифры.
6. Проверка валидации поля "CVC/CVV" при вводе некорректного значения (00).

---

## 2. Перечень используемых инструментов

Для автоматизации тестирования планируется использовать следующие инструменты:

**Python** — основной язык разработки автотестов.

**pytest** — фреймворк для написания и запуска автотестов.

**Selenium WebDriver** — инструмент для автоматизации взаимодействия с веб-интерфейсом приложения.

**Allure** — инструмент для генерации отчётов по результатам выполнения автотестов.

**MySQL** — база данных приложения, используется для проверки корректности записи результатов операций.

Выбор данных инструментов обусловлен их распространённостью, удобством использования и тем, что они были изучены в рамках обучения.

---

## 3. Возможные риски при автоматизации

В процессе автоматизации могут возникнуть следующие риски:

* изменение структуры пользовательского интерфейса, что может привести к необходимости обновления локаторов элементов;
* нестабильность автотестов из-за задержек загрузки элементов интерфейса;
* ограниченное время на выполнение проекта.

---

## 4. Интервальная оценка трудозатрат

Оценка времени выполнения работ:

| Этап                          | Оценка времени |
| ----------------------------- | -------------- |
| Подготовка окружения          | 2–3 часа       |
| Настройка проекта автотестов  | 2–3 часа       |
| Реализация автотестов         | 6–8 часов      |
| Настройка отчётов Allure      | 2 часа         |
| Отладка и стабилизация тестов | 3–4 часа       |
| Подготовка итогового отчёта   | 2–3 часа       |

**Итого:** 17–23 часа.

---

## 5. План сдачи работ

План выполнения проекта:

1. Подготовка окружения и настройка проекта.
2. Реализация автотестов.
3. Запуск автотестов и анализ результатов.
4. Формирование отчёта Allure.
5. Подготовка отчёта по автоматизации.

Планируется завершить работу над проектом до 24 марта.
